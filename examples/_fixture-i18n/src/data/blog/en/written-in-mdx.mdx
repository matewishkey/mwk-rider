`@astrojs/mdx` is a baseline dependency, which means every audited site is told
to install it. Until this file existed, neither example used it and the content
loader's glob could not have loaded it — so the requirement was asserted and
never once exercised.

This paragraph is rendered by {pipeline}, and the expression above is the point:
if the integration regresses, this page stops building and CI says so.
